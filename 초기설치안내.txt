BMS Korean Briefing 0.2.1 — 초기 설치 및 사용 안내
Windows 11 x64 / Falcon BMS 4.38.x / 한국어 오프라인 번역

1. 설치
배포 ZIP 전체를 원하는 폴더에 압축 해제합니다.
BMS-Korean-Briefing-Setup.exe를 실행합니다.
자동으로 찾아낸 Falcon BMS 설치 경로를 확인합니다.
다른 경로라면 [폴더 선택]에서 Bin, Data, User가 있는 BMS 최상위 폴더를 선택합니다.
[기존 BMS 바로가기에 자동 실행 연결]을 켜고 [설치 및 BMS 연결]을 누릅니다.
기존 바로가기는 먼저 백업되며 대상, 실행 인수, 작업 폴더와 아이콘을 보존합니다.
일반적인 사용자 쓰기 가능 경로에서는 관리자 권한이 필요 없습니다.
설치 폴더에 쓰기 권한이 없으면 임의로 보안을 해제하지 말고 폴더 권한을 확인하세요.

2. 설치 위치
<BMS 설치 폴더>\User\Plugins\BMS-Korean-Briefing
예: B:\Falcon BMS 4.38\User\Plugins\BMS-Korean-Briefing

프로그램, 번역 모델, 설정, 캐시, 기록이 위 폴더에 들어갑니다.
한국어 번역 결과: <BMS>\User\BriefingKR
PRINT 원본: <BMS>\User\Briefings
설치기는 User\Config의 g_sBriefingsDirectory 값을 읽어 경로 변경도 반영합니다.
원본 BMS 실행 파일, 런처, 게임 설정, 브리핑 파일은 수정하지 않습니다.
Plugins는 이 애드온의 설치 표준 위치이며 Falcon BMS 공식 플러그인 인증을 뜻하지 않습니다.

3. 평소 사용
설치기가 연결한 기존 바탕화면/시작 메뉴 BMS 바로가기로 실행합니다.
또는 새로 만들어진 [Falcon BMS + Korean Briefing] 바로가기를 사용합니다.
평소와 같은 BMS 런처에서 설정을 확인하고 LAUNCH를 누릅니다.
실제 Falcon BMS.exe가 감지되면 한국어 브리핑 감시기가 시작됩니다.
게임의 BRIEFING 화면에서 PRINT를 누릅니다.
페이지가 자동으로 열리고 한국어 번역 진행 상황이 표시됩니다.
새 PRINT는 연결된 기존 페이지를 갱신합니다.
BMS 종료 후 약 15초가 지나면 번역 감시기도 종료됩니다.
Windows 로그인 시 실행 감지기가 백그라운드에 시작됩니다. 2초마다 설치한 BMS의 런처와 게임을 확인합니다.
번역 앱과 모델은 BMS 실행 시 켜지며, BMS 종료 후 종료됩니다. 실행 감지기는 다음 실행을 기다립니다.

Launcher\\FalconBMS_Alternative_Launcher.exe, Launcher.exe를 직접 실행해도 자동 감지합니다.
다른 런처/작업 표시줄/바로가기로 실행한 경우에도 등록한 경로의 실제 Falcon BMS.exe를 감지합니다.
설치 전에 이미 BMS가 실행 중이었다면 설치 후 자동 연결됩니다.
설치 도중 게임을 강제로 종료하거나 새로 실행하지 않습니다.

4. BMS PRINT 설정
BMS 런처 Config의 Briefing 설정에서 브리핑 파일 출력을 활성화합니다.
HTML 또는 기본 텍스트 briefing.txt 모두 지원합니다.
실제 설치에서 g_bBriefHTML=0인 텍스트 PRINT 출력으로 검증했습니다.
PRINT 후 Briefings 폴더에서 파일이 생성/갱신되는지 먼저 확인하세요.
앱은 게임 내부 버튼을 후킹하거나 게임 프로세스에 코드를 주입하지 않습니다.

5. 한국어 번역과 화면
Python, Ollama, OpenAI API 키를 설치할 필요 없습니다.
전용 EN→KO 모델이 프로그램에 포함되어 번역 중 인터넷이 필요 없습니다.
BMS 군사용어와 반복 문구에는 검토한 번역을 적용하고 나머지는 기계번역합니다.
숫자, 시각, 주파수, 호출부호, 군사 약어 등 보호 검증에 실패한 항목은 영어로 유지합니다.
한국어 / 영어 원문 / 한영 병기, 섹션 탐색, 검색, 재번역, 인쇄/PDF를 지원합니다.
Zulu 원문은 유지하고 KST 보조 시각과 다음 날 +1일을 표시합니다.
전체 화면 게임의 포커스를 강제로 가져오는 옵션은 기본 OFF입니다.

6. 저장된 브리핑
BriefingKR의 *_KR.html을 더블클릭하면 앱 종료 후에도 브라우저에서 볼 수 있습니다.
같은 원본 파일의 번역본은 갱신됩니다. 이력은 원본 파일별 최근 번역본입니다.
여러 PRINT 버전을 모두 별도 보관하는 시간순 스냅샷 기능은 포함하지 않습니다.
HTML에는 CSS와 한영 전환 기능이 들어 있고 외부 이미지나 폰트를 요구하지 않습니다.

7. 문제 해결
페이지가 안 열림: PRINT 출력 파일과 data\\launcher-watch.log, data\\application.log를 확인하세요.
BMS가 실행 중일 때 주소 http://127.0.0.1:8765 를 직접 열어볼 수 있습니다.
브리핑 경로가 바뀜: 뷰어 [설정]의 감시 폴더를 실제 출력 위치로 맞추세요.
번역 일부가 영어: 한영 병기로 원문을 확인하고 [재번역]을 누르세요.
포트 사용 중/실행 오류: data\application.log를 확인하세요.
업데이트 설치가 막힘: 실행 중인 브리핑 앱을 종료한 뒤 설치를 다시 실행하세요.
BMS 종료/재시작 사이에는 약 15초의 유예 시간이 있습니다.
브라우저가 백그라운드 탭을 오래 중지하면 탭 생존 판정이 늦어질 수 있습니다.
설치 EXE에는 코드 서명이 없습니다. 발행자를 확인할 수 없는 환경에서는 설치를 중단하고
배포자와 파일 SHA-256을 확인하세요. 보안 기능을 끄거나 경고를 우회할 필요는 없습니다.

8. 통합 해제 및 제거
설치 폴더의 Uninstall.cmd를 실행하면 기존 BMS 바로가기를 백업에서 복원합니다.
로그인 실행 감지기 등록도 제거하며, 실행 중인 감지기는 자동 종료됩니다.
새 통합 바로가기는 일반 BMS 런처 바로가기로 바뀝니다.
나중에 사용자가 직접 바꾼 다른 대상의 바로가기는 덮어쓰지 않습니다.
프로그램과 data, BriefingKR 결과는 보존합니다.
완전 제거하려면 BMS와 브리핑 앱이 종료된 상태에서 필요한 브리핑을 백업하고
User\Plugins\BMS-Korean-Briefing 폴더를 사용자가 삭제할 수 있습니다.
BMS 원본 설치 폴더 전체나 Briefings를 삭제하지 마세요.

9. 배포
배포 ZIP과 SHA256SUMS.txt를 함께 전달하세요. BMS 게임 파일은 포함되어 있지 않습니다.
개인 설정, API 키, 캐시 DB, 실제 개인 브리핑은 배포본에 포함하지 않습니다.
자체 소스는 LICENSE.txt, 번역 모델과 라이브러리는 THIRD-PARTY-NOTICES.txt 및 licenses를 확인하세요.
이 프로그램은 Falcon BMS 개발팀의 공식 인증/지원 제품이 아닙니다.


10. 선택 사항: Ollama 로컬 AI 모델 설치와 선택
기본 내장 번역은 추가 설치 없이 사용할 수 있습니다.
뷰어의 [설정] → [번역 엔진]에서 [Ollama · 로컬 AI 모델 선택·설치]를 고릅니다.
안내의 공식 Windows 설치 페이지에서 Ollama를 설치하고 실행합니다.
[연결·모델 목록 다시 확인]을 누릅니다. 설치되어 있지만 실행되지 않았다면 [설치된 Ollama 실행]을 누릅니다.
다운로드 목록에서 TranslateGemma 4B(약 3.3 GB) 또는 12B(약 8.1 GB)를 고르고 [선택한 모델 다운로드·설치]를 누릅니다.
진행률과 오류를 표시하며 취소할 수 있습니다. 앱을 종료하면 앱에서 진행 중인 다운로드도 중단 요청합니다.
다시 다운로드하면 Ollama에서 이미 받은 부분을 재사용할 수 있습니다.
완료 후 [설치된 Ollama 모델] 목록에서 선택하고 [설정 저장]을 누릅니다. 현재 문서를 새 모델로 재번역합니다.
기존에 Ollama로 설치한 다른 모델도 자동 목록에 표시됩니다. 이름을 외워 입력할 필요가 없습니다.
다운로드 완료만으로 번역 엔진을 바꾸지는 않습니다. 기본 내장 엔진으로 언제든 돌아올 수 있습니다.
4B/12B는 다운로드 크기이며 실제 실행 메모리는 별도입니다. 로컬 AI는 게임과 GPU/RAM을 공유합니다.
설치된 모델 파일은 브리핑 앱 폴더가 아니라 Ollama가 관리하는 저장 위치에 남습니다.
참고: https://ollama.com/download/windows / https://ollama.com/library/translategemma


11. BMS 없이 설정·기록 열기
바탕화면 [BMS Korean Briefing Viewer] 바로가기 또는 설치 폴더의 BMS-Korean-Briefing-Viewer.exe를 실행하세요.
BMS 실행이나 PRINT 없이 기본 브라우저에서 설정과 저장된 브리핑을 열 수 있습니다.
서버가 꺼져 있으면 이때만 시작하고, 이미 켜져 있으면 기존 서버를 사용합니다. BMS 게임은 실행하지 않습니다.
모든 브리핑 뷰어 탭을 닫고 약 30초가 지나면 수동 뷰어 서버가 종료됩니다. BMS 실행 중이면 PRINT 처리를 위해 유지합니다.
BMS를 먼저 실행한 경우에도 이 EXE로 뷰어를 열면, 게임을 종료한 뒤 열려 있는 뷰어에서 설정을 계속 사용할 수 있습니다.
상시 설정 서버는 등록하지 않습니다. 기존 로그인 실행 감지기는 BMS 런처/게임 시작만 감지합니다.
http://127.0.0.1:8765 주소는 서버가 실행 중일 때 사용할 수 있으므로, 꺼져 있을 때는 뷰어 EXE를 먼저 실행하세요.


인게임 한국어 니보드 (KTO / F-16)
브리핑을 연 뒤 상단 니보드 생성을 누르면 현재 한국어 HTML을 이미지로 캡처해 BMS에 적용합니다.
브라우저의 실제 HTML 렌더링을 사용하므로 표·글꼴·종이 질감과 페이지 순서가 유지됩니다. 텍스트를 별도 글꼴로 다시 조립하지 않습니다.
Microsoft Edge가 필요합니다. 숨김 렌더러는 생성 중에만 실행되며 내장 자산을 사용하므로 외부 웹페이지에 접속하지 않습니다.

첫 페이지부터 한국어 브리핑 사용(기본 켜짐)
켜면 좌우 니보드 1쪽부터 적용합니다(최대 32쪽). 끄면 앞 8쪽씩을 유지하고 9쪽부터 적용합니다(최대 16쪽).
니보드 생성 창 또는 설정에서 선택할 수 있습니다. 옵션 변경 뒤 다시 생성하세요.
남는 슬롯은 백업된 원본으로 되돌려 이전 한국어 브리핑이 중복으로 남지 않게 합니다.

비율 보정
A4 종이 비율 보정(기본): HTML 문서를 니보드의 1024x2048 UV 영역에 사전 압축해 인게임 가로 늘어짐을 보정합니다.
보정 없음: 이미지의 원래 비율을 텍스처 안에서 유지합니다. 기체 모델의 표시 비율에 따라 결과가 다를 수 있습니다.

사용 및 복원
조종석 진입 전에 생성하세요. 이미 비행 중이라면 다음 조종석 진입 때 확인하세요.
게임의 Left/Right Kneeboard Inc/Dec 키로 좌우 페이지를 넘길 수 있습니다.
원본은 플러그인 data/kneeboard/original-*에 백업되며 니보드 창의 원본 니보드 복원으로 되돌립니다.
KTO의 F-16 기본 니보드 기준이며 다른 전장·기체는 지원하지 않습니다.
다른 니보드 도구와 동시에 생성하지 마세요. 마지막으로 적용한 파일이 표시됩니다.
용량을 초과하면 내용을 자르지 않고 적용을 중단합니다. 생성 PNG와 적용 기록은 data/kneeboard에 저장합니다.


프로그램 업데이트
설정 → 업데이트에서 새 버전 확인을 누를 수 있습니다. 앱 시작 때도 한 번 확인합니다.
새 버전이 있으면 다운로드 및 업데이트 설치를 누르세요. 다운로드·검증 후 앱이 잠시 닫히고 설치가 끝나면 뷰어가 다시 열립니다.
BMS 설치 경로, 번역 설정, 브리핑 기록 및 니보드 백업은 유지됩니다. 게임 프로세스는 종료하지 않습니다.
설치 파일 검증에 실패하면 실행하지 않으며, 프로그램 교체에 실패하면 이전 버전을 복원합니다.
이전 0.2.1 사용자는 자동 업데이트 화면이 없으므로 0.3.0 설치 파일로 한 번 업데이트해주세요.
